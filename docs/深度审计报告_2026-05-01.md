## 优先修复路线图

### Phase 1 — 紧急（1-2 周）

**目标**: 消除所有 P0，确保系统不会被未授权操作或数据丢失

1. **安装向导认证保护** — 加初始化状态锁 + 管理 token 校验
2. **下单幂等性** — 增加 `client_order_id` 字段，交易所 API 传 `newClientOrderId`
3. **自动下单事务保护** — `create_order` + `submit_order` 合并为单事务
4. **策略启动并发锁** — `SELECT ... FOR UPDATE` 或 Redis 分布式锁
5. **前端 XSS 修复** — 所有 innerHTML 改 textContent 或 escapeHtml
6. **WS Token 不走 URL** — 连接后首条消息发 token
7. **Redis 持久化** — `appendonly yes` + `save 60 1000`
8. **PG 备份脚本** — pg_dump cron + S3 上传
9. **CI/CD 基础** — GitHub Actions: lint + test + build
10. **TimescaleDB 部署** — 换 `timescale/timescaledb` 镜像 + hypertable

### Phase 2 — 重要（2-4 周）

**目标**: 修完 P1 中影响安全和可靠性的项

1. **异常处理治理** — 消灭 `except Exception: pass`，统一用 `logger.exception`
2. **structlog 启用** — JSON 结构化日志
3. **认证/交易端点 Rate limiting**
4. **HTTPS + 安全 Headers** — Nginx/Caddy 反向代理
5. **API 分页** — 使用已有的 `PageResponse` schema
6. **N+1 查询修复** — 批量查询替代循环内单查
7. **核心模块测试** — `test_strategy_runner.py` + `test_ws_manager.py`
8. **前端请求竞态** — AbortController + 防抖
9. **前端内存泄漏** — 页面卸载时清理监听器
10. **python-jose → PyJWT 迁移**

### Phase 3 — 优化（4-8 周）

**目标**: P2 项 + 代码质量提升

1. 前端规则构建器去重（提取共享模块）
2. 交易对数据从后端 API 获取
3. Docker compose 生产配置
4. APM + Prometheus 接入
5. 数据库索引优化
6. 审计日志体系
7. 灾难恢复方案
8. a11y 修复（键盘导航 + ARIA）
