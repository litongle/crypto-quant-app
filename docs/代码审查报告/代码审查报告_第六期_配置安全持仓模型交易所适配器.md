## 一、配置安全

### 🔴 1. 【严重】开发环境默认密钥未强制检测

文件: config.py:14-16 · docker-compose.yml:15-16

问题: Docker Compose 使用 dev-secret-key-change-me 作为默认值。
validate_production_secrets() 仅在 production 时触发。攻击者可用固定密钥生成任意 JWT。

### 🟠 2. 【中等】AES密钥派生无盐

文件: security.py:119-123

问题: SHA256直接派生无盐，攻击者获取SECRET_KEY后可离线解密所有API Key。

## 二、持仓与交易逻辑

### 🔴 3. 【严重】Position缺少联合唯一约束

文件: models/exchange.py:130

问题: 无(account_id,symbol,side)唯一约束，并发时可能重复持仓。

### 🟠 4. 【中等】OKX posSide=net未处理

文件: exchanges/okx.py:240

问题: net表示净持仓，传给后续逻辑导致方向判断失效。

### 🟠 5. 【中等】OKX永续tdMode=cash，合约无法下单

文件: exchanges/okx.py:264

问题: 永续必须用cross/isolated，用cash会返回4013错误。

### 🟠 6. 【中等】OKX时间同步偏移未应用

文件: exchanges/okx.py:40
